# CLAUDE.md

## This repository is PUBLIC

Everything here — code, comments, commit messages, branch names, issues,
pull requests and their discussion — is visible to anyone on the
internet, is indexed, and is permanent. Deleting something later does
not unpublish it.

Treat every write to this repository as a publication.

## Rules for anyone, human or agent, working here

1. **Generic content only.** Never write, commit or post anything that
   names a private organisation, a private repository, an internal
   project, plan or ticket, a customer, an employee, an internal
   hostname, URL, IP address, or an absolute filesystem path.
2. **No credentials, ever** — no tokens, keys, passwords or secrets in
   any file, commit or comment, not even expired or example-shaped
   ones. Anything environment-specific is read from an environment
   variable, never hardcoded.
3. **No internal logs, traces or config dumps.** Where evidence is
   genuinely needed to describe a problem, cut it down to the minimum
   that demonstrates the fault, with every identifier, hostname and path
   redacted — or reproduce the fault in a throwaway public example and
   show that instead.
4. **Describe the class of problem, not the specific case.** "A
   consuming project", "a downstream private repository", "a vendored
   clone" — never the real name.
5. **Re-read before you publish.** Check the exact text of an issue,
   pull request, comment or commit message against rules 1-4 before it
   is sent. Where an automated agent is doing the posting, an
   independent review pass must clear that text first — the agent does
   not clear its own draft.
6. **When in doubt, do not publish it here.** Raise it in a private
   channel instead. An over-cautious omission costs nothing; a leak
   cannot be taken back.
